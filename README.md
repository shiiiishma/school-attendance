# Учет школьной посещаемости

Клиентское веб-приложение для автоматической обработки выгрузок формы посещаемости (Яндекс / Google Формы) и формирования сводного Excel-отчета по школьному стандарту.



---

## Основные возможности

- **Многостраничный Excel-отчет:** каждая выбранная дата формируется на отдельном листе (`DD.MM.YYYY`) с сохранением всех формул (`=C{r}+E{r}`, `=SUM(...)`) и расчетом сумм.
- **Гибкий выбор периода:** выгрузка за все даты, за конкретный месяц (например, сентябрь или октябрь), за произвольный интервал дат или за один выбранный день.
- **Статистика и сводки:**
  - Автоматический подсчет отсутствующих по параллелям (1–4, 5–9, 10–11 классы).
  - Быстрое копирование текста сводки для отправки в мессенджер руководству.
  - Определение классов, не сдавших отчет (должников).
- **Умная обработка данных:**
  - Нормализация названий 29 классов (исправление регистра, лишних пробелов, похожих букв латиницы).
  - Автоматическое разрешение повторных ответов за один день (учитывается последняя запись с уведомлением в интерфейсе).
- **Конфиденциальность (152-ФЗ):** персональные данные обрабатываются локально в браузере пользователя и никуда не передаются по сети.

---

## Быстрый запуск


Откройте файл **`index.html`** в любом современном браузере (двойной клик мышью). Доступ к интернету не требуется.


## Структура файлов

- **`index.html`** — разметка интерфейса и панель управления отчетами.
- **`style.css`** — стили и адаптивная верстка.
- **`app.js`** — парсинг выгрузок формы, расчет статистики и сборка Excel-книги.
- **`exceljs.min.js`** — автономная библиотека для генерации файлов Excel.

- **`Тестовая_выгрузка_формы_2026.xlsx`** — синтетический набор данных на 27 дней (сентябрь + начало октября 2026) для тестирования всех режимов.
